# Bhupendra Patil — Portfolio

A responsive React portfolio built with Vite, Framer Motion, and Lucide icons.

## Run locally

1. Install a current LTS version of Node.js.
2. Extract this ZIP and open the extracted `Assignment9_Bhupendra_Portfolio_Final` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build for deployment

Run `npm run build`. The production website is generated in the `dist` folder.

## Included

- Home, About, Projects, Skills, Contact, and Education content
- Mobile navigation and responsive layouts for phone, tablet, laptop, and desktop sizes
- Reduced-motion support; cursor smoke is disabled on touch devices and when reduced motion is requested
- Animated rotating role text and red cursor smoke on mouse/trackpad devices
- Profile photo at `public/profile.jpg`
- GitHub links for TraceMate, MarketIQ, and Body Fixer Fitness
- Real Estate Voice Agent project card with an honest note that the old demo token expired

## Notes
